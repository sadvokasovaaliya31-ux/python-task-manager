# Python Task Manager

## Описание проекта
Консольное приложение для управления задачами. Программа позволяет пользователю создавать, просматривать, редактировать и удалять задачи, а также искать их по названию. Решает проблему организации личных дел и контроля их выполнения.

## Возможности
- Добавление новых задач.
- Просмотр списка всех задач с их статусами.
- Отметка задачи как выполненной.
- Удаление задачи по ID.
- Поиск задач по ключевому слову.
- Очистка всего списка задач.
